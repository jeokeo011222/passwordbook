# 🔒 密码本 PasswordBook

一款纯本地、离线加密的 Windows 密码管理工具。所有数据存储在本机 SQLite 数据库中，使用 **AES-256-GCM** 对称加密 + **PBKDF2** 密钥派生，无需联网，无账号注册，不发送任何数据。

---

## 🔐 安全设计

### 加密架构

```
主密码（用户输入）
    │
    ▼ PBKDF2-SHA256 (600,000 iterations)
派生密钥 Key (32 bytes)
    │
    ▼ AES-256-GCM
    │
每条密码记录单独加密：
    ┌──────────────┬──────────┬──────────┐
    │ 12字节 Nonce │ 密文+Tag │ Base64   │
    └──────────────┴──────────┴──────────┘
```

- **PBKDF2 60 万次迭代**：抗暴力破解，GPU/ASIC 每小时尝试次数极低
- **每条记录独立 Nonce**：相同明文加密后密文完全不同，防止彩虹表
- **AES-256-GCM 认证加密**：不仅加密还防篡改，Tag 校验失败数据拒绝解密
- **零明文驻留**：解锁后密码在内存中以密文存储，进入锁定态立即清除敏感缓冲区

### 主密码丢失怎么办？

**无法找回。** 这是有意设计——如果程序能找回你的主密码，意味着主密码被存在某个地方，那加密就白做了。

建议：
- 设置一个强度足够但你能记住的主密码
- 定期用「备份」功能导出加密备份文件（.pbk），备份文件用同一个主密码保护

### 数据存储位置

```
%APPDATA%\passwordbook\
├── password.db        # SQLite 加密数据库
└── tray_debug.log     # 托盘运行日志（不含敏感数据）
```

- `%APPDATA%` 默认在 `C:\Users\<用户名>\AppData\Roaming\`
- 数据库文件可以直接复制备份/迁移到另一台机器

## 🛠 设置

点右上角 **「⚙」** 打开设置面板：

| 选项 | 说明 |
|------|------|
| **自动锁屏** | 空闲 N 秒后自动锁定（0 = 不自动锁） |
| **主题** | 跟随系统 / 浅色 / 深色 |
| **开机自启** | 勾选后写入注册表 Run 项，开机自动启动 |
| **修改主密码** | 验证旧密码 → 重新加密所有记录 → 事务提交 |

## 🧪 密码生成器

点左侧 **「密码生成器」**，可配置：

- **长度**：8–128
- **字符集**：大写 / 小写 / 数字 / 符号
- **排除易混字符**（可选）
- **一键复制**到剪贴板

---

## 📥 浏览器密码导入

支持 Chrome / Edge / Firefox 导出的 CSV 格式：

1. Chrome 地址栏输入 `chrome://settings/passwords`
2. 右上角 `⋮` → 导出密码 → 输入系统密码 → 保存 CSV
3. 在密码本中点 **「CSV 导入」** → 选择文件 → 选择目标分类 → 确认

## 🆘 常见问题

**Q: 忘记主密码怎么办？**
A: 无法找回。请用之前导出的备份文件恢复（备份文件也需要主密码解密）。

**Q: 数据会上传到云端吗？**
A: 不会。程序是纯离线的，不发送任何网络请求。

**Q: 支持哪些操作系统？**
A: 当前仅 Windows。UI 框架 eframe 支持跨平台，但托盘、注册表等功能绑定 Windows API。

**Q: 数据库可以手动备份吗？**
A: 可以。直接复制 `%APPDATA%\passwordbook\password.db` 即可。恢复时关闭程序再复制回来。

**Q: 为什么没有浏览器扩展/自动填充？**
A: 自动填充需要浏览器 Native Messaging 协议配合，设计复杂且各浏览器实现不同。目前保持简洁。
